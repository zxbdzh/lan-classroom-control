# 机房现场验收

发布前必须分别在 Windows 7 SP1 x64 和 Windows 10 x64 学生机上完成。本机或 CI 结果不能替代现场结论。

## 环境

- 教师端 1 台，学生端至少覆盖 20 台，最终验收覆盖目标上限 60 台。
- 使用生产交换机、VLAN、组播侦听和实际布线；记录交换机型号、终端型号、系统版本、DPI 与网卡驱动。
- 教学 VLAN 不映射公网入站端口；无认证明文版本不得部署到非受信网络。

## 必验项目

1. 自动发现与重连：所有学生无人工操作接入；教师重启、学生重启和短时断网后自动恢复稳定设备 ID 与分组。
2. 广播：以 1920×1080 教师画面连续运行 30 分钟，记录 20 FPS 下首帧、P50、P95、最大延迟、丢帧率、CPU、内存和交换机端口流量；断开组播后 800 ms 级切到 TCP 备用链路。
3. 巡视与全屏：同时显示全部缩略图；随机打开、关闭并远控 10 台，确认坐标、键盘、宽高比和返回缩略图流。
4. 黑屏肃静：全部显示器显示教师提示语并锁定键鼠；教师解除和 10 秒心跳租约超时均能恢复。
5. 网络管控：禁止公网 IPv4/IPv6、DNS、HTTP/HTTPS/QUIC，同时验证学生仍可访问同 VLAN 主机、教师 TCP 9528、UDP 9527/9529/9530、TCP 9531，并完成文件分发。
6. 文件分发：向 60 台下发单文件与嵌套文件夹，验证断点续传、SHA-256、目录结构和公共桌面“课堂文件”。
7. 进程与永久策略：结束普通进程；拒绝 PID 复用和系统进程；黑名单在断线、重启和“全部恢复”后仍生效，只有教师解除命令删除规则。
8. 服务与更新：标准用户登录后 Agent 自动启动；LocalSystem 服务跨会话通信；安装、覆盖升级、签名更新失败回滚和卸载均无残留服务、防火墙规则或启动项。

## 通过标准

- 60 台全部完成自动接入，稳定运行期间无持续离线。
- 广播端到端 P95 小于 100 ms，首帧小于 1 秒，30 分钟无不可恢复中断。
- 所有控制命令有设备级 ACK；失败设备可定位、重试，恢复动作不清除永久黑名单。
- Win7 与 Win10 各完成一次安装、重启、升级、回滚和卸载闭环。
