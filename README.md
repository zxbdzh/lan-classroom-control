# 局域网机房控制系统 v2

[English](README.en.md)

**面向学校机房和培训教室的 Windows 局域网 C/S 管控系统。** 教师端以座位拓扑管理 20–60 台固定学生机，学生端由 Windows 服务和登录会话代理协作运行。

## 功能

- 座位图：按主机名尾号初排，支持拖动、空座、行列设置和全班/分组/已选作用域。
- 设备标记：点击设备名复制完整名称，支持持久备注及按备注搜索；同名设备可分别标记。
- 屏幕广播：20 FPS MJPEG UDP 组播，800ms 未收到首帧时使用独立 TCP 媒体通道降级；广播期间可锁定学生键鼠。
- 巡视与远控：主屏缩略图默认 640×360 / 1 FPS，巡视只发送一份 TCP 画面；远控通过随包附带的 UltraVNC 独立窗口运行。
- 黑屏肃静：显示教师提示语并限制键鼠；远控时临时让出该台屏幕，退出后按仍有效的课堂状态恢复。
- 网络管控：通过 Windows 防火墙阻止教师及明确放行网段以外的 IPv4/IPv6 连接，保留控制、文件与远控。防火墙关闭或域策略限制时明确报告失败。
- 文件分发：可拖入文件/文件夹加入列表，点击“开始分发”后发送；最多 4 台并发、合计约 4 MiB/s 限速；SHA-256 校验落盘、失败设备可重试续传，同名文件夹保留副本。服务模式保存到公共桌面“课堂文件”。
- 应用策略：支持全班持续禁用、新设备自动继承及按范围限制；软件禁用总开关可暂停/恢复全部规则，配置重启后保留。规则页直接解除并显示执行结果，进程页支持搜索及按 PID + 创建时间结束进程。新规则填写含 `.exe` 的程序名，兼容已有完整路径规则。这是启动后关闭的策略，无法保证程序完全没有执行瞬间。
- USB 存储管控：按全班、分组或已选设备限制/恢复可移动磁盘的读写与执行，保留键鼠等外设；显示设备级策略回执，断线后尝试恢复原策略。
- 设备维护：关机、重启、注销、网络唤醒和设备扫描。
- 操作记录：命令级和设备级状态，SQLite/WAL 持久化，保留 90 天并可导出 CSV。
- 主题：浅色默认，支持深色；目标分辨率为 1366×768，支持 100%–125% 缩放。

## 系统要求

- Windows 7 SP1 x64 或 Windows 10 x64。
- Python 3.8（源码运行）；发布冻结运行时固定为官方 CPython 3.8.10；PyQt5 5.15.2。
- 学生端安装和服务运行需要管理员权限。
- Windows 7 需要 KB4490628、KB4474419 和 KB2999226（Universal C Runtime）。

Win7/Win10 真机兼容性必须在发布前按机型验证。当前自动化开发环境为 Windows 11，不能替代该项验证。

## 运行

```powershell
uv sync --locked --python 3.8 --group dev
uv run teacher
uv run student
```

生产部署使用安装器。学生端生产架构为：

```text
Windows 服务（网络/防火墙/进程/电源/教师连接）
    ↕ Windows 命名管道
登录会话代理（覆盖层/截屏/键鼠，默认无托盘）
UltraVNC 按需服务（独立远控画面与输入）
独立恢复守护（服务崩溃、租约失效后的恢复重试）
```

## 教师端页面

教师端包含“教室、巡视、文件、应用策略、设备维护、操作记录、设置”七个工作区。顶部始终显示作用域和常用课堂命令；批量关机、重启、注销及解除应用规则需要确认。应用策略页默认创建全班规则，也可切换仅当前作用域；页面右上角总开关暂停或恢复全部软件限制。

## 网络端口

| 端口 | 协议 | 用途 |
|---|---|---|
| 9527 | UDP | 教师发现广播 |
| 9528 | TCP | 控制、心跳、ACK |
| 9529 | UDP | 教师屏幕组播 |
| 9530 | UDP | 学生巡视画面上行 |
| 9531 | TCP | 媒体/批量降级通道 |
| 15900 | TCP | UltraVNC 独立远控，仅会话期间启动 |

默认组播地址为 `239.255.95.29`。

安装器会为本项目程序添加入站放行规则，覆盖公共、专用和域网络，卸载时移除；添加失败会显示错误。源码运行需自行允许对应 Python 程序通信。

## 控制协议

v2 状态命令使用稳定命令 ID、单调修订号、300ms/700ms 重试、`received`/`applied` 双阶段 ACK、设备级结果和去重。同一学生依 TCP 收包顺序执行，远控键鼠由 UltraVNC 负责。广播、肃静、网络限制、巡视、远控和键鼠锁属于临时控制；默认 10 秒心跳租约到期后尝试恢复，失败保留并重试。代理及独立恢复守护还处理服务异常退出。永久应用黑名单不会被断线、“全部恢复”或重启清除。

默认禁网仅保留教师地址和回环、发现所需地址；其他内网资源请在设置的内网 CIDR 中明确放行。不要把能转发外网的代理地址放入白名单后仍期待它被阻断。

USB 存储入口位于“设备维护”，沿用顶部作用域。学生端须有管理员权限，教师端和学生端均需升级到支持该命令的版本；旧学生端无法执行时会返回失败。该功能限制 Windows 识别为可移动磁盘的读、写及执行权限，不禁用 USB 控制器、键鼠、Hub 或网卡，不覆盖固定磁盘类 USB 设备、手机 MTP/WPD 或启动前的 U 盘引导。“策略已应用”仅表示设置已写入并回读确认，已挂载设备可能需重新插拔或重启；[微软说明访问权限变更可能直到重启系统才生效](https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-admx-removablestorage)。限制和恢复都不强制弹出设备或重启，不保证即时封禁，也不能代替 BIOS 启动限制或管理员权限管理。

USB 限制属于临时课堂控制：断线、心跳租约过期、点击“恢复 USB 存储”或“全部恢复”时，按本次限制前保存的值恢复；服务重启或异常退出后也会尝试恢复，失败保留备份并重试。原先已被学校策略禁用的访问不会被强行开启，域策略仍可能重新覆盖本地设置。

远控入口：巡视 → 打开学生画面 → 远程控制。教师端收到学生端 UltraVNC 服务及 RFB 就绪回执后才打开 Viewer；Viewer 启动成功与实际连入桌面分别判断。关闭 Viewer 会发送恢复命令，其他黑屏设备不受影响。

## 安全边界

本版本按项目决策采用自动发现、自动连接、无身份认证和明文控制通道。任何能进入同一局域网并访问端口的主机都可能伪装教师或观察/篡改流量。系统只能部署在隔离且受信任的教学 VLAN，禁止映射到公网。

发布更新包必须同时具备 SHA-256 和 Ed25519 清单签名。发布私钥不得提交到仓库；仓库只包含学生端信任的公钥。

### 部署学生端更新

- 下载 `LanClassroom-Student-Update.zip`，在教师端“设备维护 → 部署签名更新”直接选择该文件，无需解压或另外下载清单、签名。
- 新更新包需要先安装支持单文件更新包的教师端；旧学生端仍接收原始已签名载荷，不需要先更换学生端才能接收更新。教师端更新请使用教师端安装器。
- 仍兼容旧式三文件：`LanClassroom-Student.zip`、`LanClassroom-Student.zip.manifest.json`、`LanClassroom-Student.zip.sig` 必须位于同一目录，选择其中的 ZIP。
- “全部”以服务端当前在线连接为准；“选中”和“分组”只通知对应设备。验签失败与没有可通知的在线设备分别提示，不再合并为同一错误。

## 测试

```powershell
uv run --locked --group dev pytest tests -q
```

测试覆盖协议校验、媒体分片/重组与 TCP 降级、命令重试/去重/租约、SQLite 状态、进程保护、网络规则、断点文件传输、签名更新、服务 IPC、师生集成和 Qt 离屏布局。

本机真实 UDP 组播传输门禁（默认 96 KiB/帧、20 FPS、100 帧，要求投递率不低于 99%、P95 不高于 100 ms）：

```powershell
uv run --locked python scripts/v2_network_probe.py
```

该命令验证本机真实 socket、分片和重组路径，不代替交换机及 20–60 台终端现场测试。

## 构建发布

源码开发或本地打包前先下载固定 UltraVNC：

```powershell
uv run --locked python scripts/prepare_ultravnc.py
```

脚本校验上游 ZIP 的 SHA-256，只提取 x64 程序与配套 DLL，不执行安装器、不安装驱动。安装包及更新包包含原版程序、许可与上游来源。固定版本为 1.8.3.2；更新版本须重新做兼容验收。

发布工作流生成独立教师/学生安装器。学生端分别打包服务和会话代理，安装器注册自动服务和登录启动项。构建完成后，Actions 创建 Release 草稿，以 `RELEASE.md` 作为前言并追加 GitHub 自动生成的 Release Notes，审核后再人工发布。同一标签的任务重跑会覆盖草稿附件并保留首次生成的说明；Release 一经正式发布，工作流将拒绝覆盖。创建 `v*` 标签前需在 GitHub Actions 配置 `UPDATE_SIGNING_PRIVATE_KEY_B64`，内容为与 [update_public_key.pem](common/update_public_key.pem) 对应私钥 PEM 的 Base64。

Release 构建还会解析教师端、学生服务、会话代理、Python/Qt 核心和安装器的 PE 头；任何目标的最低 OS 或子系统版本高于 Windows 7 的 `6.1` 都会直接阻止发布。该静态门禁不能替代 Win7/Win10 真机安装与运行验收。

本轮验收范围、未测项目及后台虚拟机入口见 [UltraVNC 接入验收](docs/ultravnc-acceptance.md)。

本地生成新密钥（仅初始化信任根时执行）：

```powershell
uv run python scripts/release_manifest.py keygen `
  --private update-private.pem `
  --public common/update_public_key.pem
```

私钥应立即移入凭据系统，并从工作目录安全删除。
